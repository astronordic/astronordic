## What I build

**Discord infrastructure** — moderation, private support threads, ticket queues, hierarchical admin panels, affiliate and rewards programs. Rules compiled into the platform's own automod so they hold even when the bot is down.

**Fintech** — Pix cash-in and cash-out, escrow with funds held in a subaccount until delivery, an append-only ledger where every balance is a sum of entries rather than a stored number, and payouts and refunds that stay correct under retry.

**Web products** — Next.js storefronts and admin panels, multi-tenant auth, static institutional sites.

## How I work

I care about the failure paths more than the happy one. Money code is written so that replaying a request cannot double a credit, an expired order cannot silently swallow a payment, and a refund cannot reopen a settled deal. Tests target those invariants directly.
